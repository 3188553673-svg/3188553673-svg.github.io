# 放学大乱斗

[打开游戏](https://3188553673-svg.github.io/afterclass-arena/) · [练习搓招](https://3188553673-svg.github.io/afterclass-arena/?mode=training) · [下载局域网主机包](https://3188553673-svg.github.io/afterclass-arena/afterclass-arena-lan.zip)

从七名斗士中选人，可挑战电脑、在同一把键盘上双打，或进入训练场对木桩练习。打开游戏里的「出招表」可以查看当前角色的方向输入和招式。手机和平板可用触屏操作。

局域网混战支持最多四人。房主在电脑上解压主机包，Windows 双击「启动游戏.cmd」，Apple 芯片 Mac 双击「启动游戏.command」。在游戏里选择「局域网」并创建房间。同一 Wi-Fi 下的朋友用浏览器打开邀请链接，或扫码加入。Linux 和 Intel Mac 可使用 Node.js 18 或更高版本运行 `node server.mjs --open`。
