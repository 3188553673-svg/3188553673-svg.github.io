# 放学大乱斗 v3.0

[开始格斗](https://3188553673-svg.github.io/afterclass-arena/v3.0/) · [进训练场](https://3188553673-svg.github.io/afterclass-arena/v3.0/?mode=training) · [下载局域网主机包](https://3188553673-svg.github.io/afterclass-arena/v3.0/afterclass-arena-lan-v3.0.zip)

每回合 60 秒，打空血条或时间到时剩余血量领先即可得分，先赢两回合获胜。七名斗士有各自的普通技、方向派生和必杀技，选人时可以搭配援助。支持人机、同机双人、固定木桩训练和最多四人的局域网混战。

| 操作 | 玩家 1 | 玩家 2 |
| --- | --- | --- |
| 左右移动 / 上方向 / 防御 | A、D / W / S | ←、→ / ↑ / ↓ |
| 普攻 / 跳 / 冲刺 | J / K / L | 1 / 2 / 3 |
| 远攻 / 必杀 / 援助 | U / I / O | 4 / 5 / 6 |
| 地面三连 / 跳攻 | J › J › J / K › J | 1 › 1 › 1 / 2 › 1 |
| 防御反击 / 上挑 | S + J / W + J | ↓ + 1 / ↑ + 1 |

手机使用方向键与六个动作键。每位斗士的出招表可切换两套键盘和触屏标注。局域网混战由房主下载主机包并完整解压，Windows x64 双击「启动游戏.cmd」，Apple 芯片 Mac 双击「启动游戏.command」。房主创建房间后，同一 Wi-Fi 的其他设备扫码加入。Linux 和 Intel Mac 可使用 Node.js 18 或更高版本运行 `node server.mjs --open`。
