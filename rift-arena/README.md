# 峡谷对决 · 1v1

直接游玩：<https://3188553673-svg.github.io/rift-arena/>。联机服务器已部署在 Render Free，玩家无需下载或安装 Node.js。

一个在浏览器中直接游玩的原创单路 MOBA。选择苍穹骑士、月影游侠、星辉术士或翡翠剑客，与朋友联机单挑，也可以和服务器电脑对手练习。

包含四位原创骨骼动画英雄、纹理石桥、雕刻防御塔和水晶、右键移动与普攻、QWER、闪现/治疗、兵线与补刀、金币经验、装备商店、防御塔、泉水回城、死亡复活与水晶胜负。人物技能按代表机制重做，数值为本作独立平衡，并非完整《英雄联盟》或官方客户端。

## 游玩

进入网页，选择英雄和代号，创建房间并分享邀请链接。朋友加入后，双方准备，由房主开始。只有摧毁敌方防御塔后才能攻击水晶。电脑练习可直接开局。

- 右键地面：移动；右键敌人：追击并普攻。
- Q/W/E/R：朝指针施放技能；R 在 6 级解锁。
- D：闪现；F：治疗；B：回城；P：装备商店；S：停止。
- A 再左键：攻击移动；空格：镜头回到英雄。
- 在己方泉水附近或死亡时购买装备；技能随等级自动成长。

## 联机与运行

双方各自连接 Node.js 权威服务器的 HTTPS/WSS。无需处在同一 Wi-Fi，不使用浏览器点对点穿透。网页通过 `connection.json` 读取服务器地址；由服务器托管时自动返回同源地址。

本地开发使用 Node.js 22+：`npm start`；浏览器打开 <http://localhost:9100>。`npm test` 执行服务器、对局规则和联机测试。

部署在 Render 时使用 `PORT` 环境变量并监听 `0.0.0.0`。免费实例闲置 15 分钟会休眠，唤醒约需一分钟；重新部署或实例重启会清空当前房间。不要为此部署自动保活任务。

## 文件

`server.js` 与 `server/`：服务器和权威对局逻辑；`shared/definitions.js`：英雄、技能和装备元数据；`scene.js`：Three.js 三维场景；`app.js` 与 `network.js`：界面、输入和联网；`tests/`：行为验证。

Three.js 的 MIT 许可证在 `vendor/THREE-LICENSE.txt`。角色和场景为本项目原创网格、动画与材质；四张头像使用内置图像生成工具制作。

## 原创美术与性能更新 0.3

移动增加本地意图预测与服务器序号确认，权威位置持续校正；控制、停止、死亡、传送和网络停顿有单独处理。服务器仅在对局进行时固定20Hz推送，大厅与结束状态按变化发送，消除命令触发的重复运动采样，按住右键的转向发送间隔由160ms改为65ms。角色伤害、命中、金币等仍由服务器决定。

场景合并小兵同骨骼分组几何、隐藏拾取体绘制、关闭小兵实时投影；角色和建筑保留实时阴影。菜单可选自动或高画质，自动模式在持续慢帧时调整渲染分辨率，不减少模型面数。HUD显示FPS和网络往返时间。

固定战斗场景、1187×619 Chrome测试：相同DPR 1.7，绘制调用225→130，渲染CPU p95 2.4→1.6ms，前后均120FPS。相同画面中提交三角面17,730→105,804，新增模型细节通过合批降低绘制提交。这是本机对照；公网延迟仍受玩家线路影响。

`original-heroes.js`包含四套原创蒙皮网格与骨骼动画；`scripts/generate-hero-textures.py`可复现共享材质图。`arena-environment.js`生成场景纹理与合批地形。慢连接下服务端合并未发送的状态，并优先发送指令确认；客户端每帧最多应用一个连续对局状态，避免收到一批快照时重复重绘。
