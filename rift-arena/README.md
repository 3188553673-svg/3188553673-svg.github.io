# 峡谷对决 · 1v1

直接游玩：<https://3188553673-svg.github.io/rift-arena/>。联机服务器已部署在 Render Free，玩家无需下载或安装 Node.js。

一个在浏览器中直接游玩的单路 MOBA 原型。选择盖伦、艾希、拉克丝或易大师，与朋友联机单挑，也可以和服务器电脑对手练习。

包含原创几何美术、右键移动与普攻、QWER、闪现/治疗、兵线与补刀、金币经验、装备商店、防御塔、泉水回城、死亡复活与水晶胜负。人物技能按代表机制重做，数值为本原型独立平衡，并非完整《英雄联盟》或官方客户端。

## 游玩

进入网页，选择英雄和代号，创建房间并分享邀请链接。朋友加入后，双方准备，由房主开始。只有摧毁敌方防御塔后才能攻击水晶。电脑练习可直接开局。

- 右键地面：移动；右键敌人：追击并普攻。
- Q/W/E/R：朝指针施放技能；R 在 6 级解锁。
- D：闪现；F：治疗；B：回城；P：装备商店；S：停止。
- A 再左键：攻击移动；空格：镜头回到英雄。
- 在己方泉水附近或死亡时购买装备；技能随等级自动成长。

## 联机与运行

双方各自连接 Node.js 权威服务器的 HTTPS/WSS。无需处在同一 Wi-Fi，不使用浏览器点对点穿透。网页通过 `connection.json` 读取服务器地址；由服务器托管时自动返回同源地址。

本地开发使用 Node.js 22+：`npm start`；浏览器打开 <http://localhost:9100>。`npm test` 执行服务器、对局规则和联机测试。

部署在 Render 时使用 `PORT` 环境变量并监听 `0.0.0.0`。免费实例闲置 15 分钟会休眠，唤醒约需一分钟；重新部署或实例重启会清空当前房间。不要为此部署自动保活任务。

## 文件

`server.js` 与 `server/`：服务器和权威对局逻辑；`shared/definitions.js`：英雄、技能和装备元数据；`scene.js`：Three.js 三维场景；`app.js` 与 `network.js`：界面、输入和联网；`tests/`：行为验证。

Three.js 的 MIT 许可证在 `vendor/THREE-LICENSE.txt`。场景、角色和界面图形均由代码重新绘制，未打包游戏客户端或官方模型、语音、贴图。

## 性能修复 0.2

移动增加本地意图预测与服务器序号确认，权威位置持续校正；控制、停止、死亡、传送和网络停顿有单独处理。服务器固定20Hz推送，消除命令触发的重复运动采样，按住右键的转向发送间隔由160ms改为65ms。角色伤害、命中、金币等仍由服务器决定。

场景合并小兵同骨骼分组几何、隐藏拾取体绘制、关闭小兵实时投影；角色和建筑保留实时阴影。菜单可选自动或高画质，自动模式在持续慢帧时调整渲染分辨率，不减少模型面数。HUD显示FPS和网络往返时间。

固定战斗场景、1187×619 Chrome测试：相同DPR 1.7，绘制调用225→183，渲染CPU p95 2.4→2.1ms，前后均120FPS。这只是本机对照，不能证明每台电脑或校园网络均流畅。资源和规则仍是原型，尚未达到一比一复刻；此次没有将未经授权的原版模型加入公开网页。

`hero-assets.js`提供通用授权GLB模型与动画加载接口，默认模型注册表为空；新增Three官方MIT loader工具存放在vendor。研究资源保存在不发布的work目录，未进入公开仓库。
