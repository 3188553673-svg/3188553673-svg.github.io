# 放学后禁止加练 v0.2

[打开校园地牢](https://3188553673-svg.github.io/afterhours-arcade/v2/) · [下载局域网主机包](https://3188553673-svg.github.io/afterhours-arcade/v2/afterhours-lan-v0.2.zip)

用科比的训练球、钢铁侠的掌心脉冲、灭建国的家长签章或奶龙的吨吨奶瓶开局。每个角色各有独立的主动技能，途中可以更换武器，最多携带两把。

每层都有随机相连的房间。清场后可以自行走门、回头拿装备或去商店。钢胆侠、跑早操的灭霸、直升机机长和冒牌奶龙分别守住一层。拿到首领战利品后进入传送门，前三层结束时各选一个天赋。

| 操作 | 玩家一 | 同机玩家二 |
| --- | --- | --- |
| 移动 | WASD | 方向键 |
| 攻击、技能、闪避 | J、K、L | 1、2、3（也可用逗号、句号、斜杠） |
| 切换武器 | Q | 4 |
| 开箱、拾取、购买、进传送门 | E | 5 或回车 |

单人和同机双人可直接网页试玩。手机可用触屏摇杆和动作按钮。局域网支持两到四名玩家。房主下载并解压主机包，打开对应系统的启动文件创建房间，其他设备连上同一 Wi-Fi 后扫码入房。主机包里有服务端、启动器和操作说明。
